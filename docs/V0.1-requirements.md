# 《Coreward / 地核守望》第一版需求 V0.1

> 类型：2D 单人采掘 + 波次防守 Demo  
> 平台：PC Web / H5（键鼠优先）  
> 单局目标时长：8～12 分钟  
> 版本目标：验证“冒险下潜采矿—赶回基地防守—升级后挖得更深”是否足够有趣。

## 1. 产品定位

这不是《Dome Keeper》的内容复刻，而是借用它最有价值的结构：

1. 安静、有探索感的地下采掘；
2. 周期性、越来越危险的基地防守；
3. 同一批资源必须在“采掘效率”和“防御能力”之间取舍；
4. 玩家不断面对一个问题：**再挖一点，还是现在回去？**

第一版只验证这个循环，不做完整 Roguelite，不追求长线内容量。

## 2. 第一版体验目标

玩家应在开始后 1 分钟内完成一次完整体验：

```text
离开基地 → 挖开土层 → 找到矿石 → 搬回基地 → 购买升级 → 抵挡第一波敌人
```

期望情绪曲线：

- 采掘阶段：安静、专注、带一点时间压力；
- 警报阶段：犹豫要不要继续深入；
- 防守阶段：短促、明确、有操作反馈；
- 升级阶段：立刻感到自己变强，并想再深入一层。

## 3. 核心设定

玩家守护的是一座坠落在陌生星球上的“地表核心站”。核心站正在从地下抽取能源，但活动会周期性吸引地表生物。

玩家操控一台小型采掘机：向地下开路、寻找晶矿、把晶矿运回核心站，并在敌袭时接管炮台。

第一版采用这个简单设定即可，不加入剧情对话、NPC、任务系统。

## 4. 单局规则

### 4.1 胜负条件

- 胜利：在地下找到并带回“地核晶体”，随后守住最终一波进攻；
- 失败：核心站生命值降至 0；
- 单局地图固定为小型地图，目标局长 8～12 分钟；
- 支持死亡后立即重新开始同一局，不做永久成长。

### 4.2 核心循环

1. **采掘**：进入地下，破坏土块并寻找晶矿；
2. **运输**：携带有限数量的晶矿返回地表；
3. **决策**：用晶矿升级采掘、移动、武器或基地；
4. **防守**：警报结束后敌人从左右两侧袭击核心站；
5. **深入**：敌人增强，玩家依靠升级挖到更深区域；
6. **终局**：取得地核晶体，触发最终波，守住即胜利。

## 5. 场景与地图

屏幕采用固定横向构图：上方约 25% 是地表基地与战斗区，下方约 75% 是可挖掘地下。

### 5.1 地下地图

- 逻辑尺寸建议：36 格宽 × 28 格深；
- 地图左右边界不可穿越；
- 每局生成土层和矿脉，但第一版可使用 3 个固定种子保证可调试性；
- 玩家只能破坏上下左右相邻方块；
- 已挖开的空间永久保留；
- 不做地下敌人、陷阱、液体、坍塌与复杂地形。

### 5.2 方块类型

| 方块 | 特征 | 第一版作用 |
| --- | --- | --- |
| 松土 | 1 次挖开 | 基础通道 |
| 硬岩 | 初始需 3 次，升级后减少 | 制造深度阻力 |
| 晶矿 | 挖开后掉落资源 | 通用升级货币 |
| 地核外壳 | 高耐久 | 包围最终目标 |
| 地核晶体 | 唯一 | 带回基地后触发终局 |

### 5.3 资源分布

- 浅层放置少量晶矿，保证第一轮能完成一次升级；
- 中层矿量增加，并由硬岩提高时间成本；
- 深层放置地核晶体；
- 单局资源总量应允许购买约 60% 的升级，迫使玩家取舍，而不是全部点满。

## 6. 玩家采掘机

### 6.1 操作

| 输入 | 行为 |
| --- | --- |
| W/A/S/D 或方向键 | 四方向移动；朝阻挡方向持续输入时挖掘 |
| E | 拾取、放下晶矿；基地内打开升级面板 |
| Space | 基地内进入或退出炮台 |
| Esc | 暂停 |

### 6.2 基础属性

- 移动速度；
- 挖掘伤害；
- 最大携带量：初始 3 块晶矿；
- 携带越多，移动越慢；
- 采掘机本身不受伤，失败只由基地生命决定。

### 6.3 运输表现

晶矿应作为可见物跟随或拖挂在玩家身后，而不只是背包数字。这样能让“收获”和“负重”一眼可见，并自然产生舍不得丢下资源的心理。

## 7. 时间与波次

- 每轮由“采掘期 + 警报期 + 防守期”组成；
- 第一轮采掘期约 45 秒，之后根据测试在 45～60 秒间调整；
- 敌袭前 12 秒出现明显倒计时；
- 最后 5 秒加强灯光闪烁、音效和屏幕边缘警示；
- 防守时仍允许玩家留在地下，但基地无人操作武器，通常会承受严重伤害；
- 防守结束后立刻进入下一轮采掘期；
- 普通波次建议 5 波，第 6 波为取得地核晶体后的最终波。

关键原则：倒计时必须始终可见，但不能遮挡挖掘视野。

## 8. 防守战斗

### 8.1 基地

- 基地生命：100；
- 基地武器：一门可沿半圆轨道旋转的能量炮；
- 基地受击有裂纹、震动和生命条反馈；
- 波次间不会自动完全恢复，只能通过升级修复。

### 8.2 武器操作

- A/D 或左右方向键旋转炮口；
- 按住鼠标左键或 Space 连续射击；
- 武器有短暂过热机制，避免无脑持续扫射；
- 命中提供闪光、击退、受击音和清晰伤害反馈。

### 8.3 敌人

第一版只做 3 种敌人：

| 敌人 | 路径 | 行为 | 设计目的 |
| --- | --- | --- | --- |
| 爬行兽 | 地面左右两侧 | 接近后持续啃咬 | 基础目标，测试瞄准与伤害 |
| 飞行虫 | 空中曲线接近 | 到达攻击距离后发射弹丸 | 迫使玩家切换瞄准方向 |
| 重甲兽 | 地面 | 速度慢、生命高、伤害高 | 制造优先级选择 |

- 第 1 波只出现爬行兽；
- 第 2～3 波加入飞行虫；
- 第 4 波以后加入重甲兽；
- 最终波混合三种敌人，持续约 35～45 秒；
- 第一版不做 Boss、元素抗性、复杂状态与敌人掉落。

## 9. 升级系统

所有升级使用同一种“晶矿”，降低第一版理解成本。

| 分支 | 一级 | 二级 | 取舍意义 |
| --- | --- | --- | --- |
| 钻头 | 挖掘伤害 +50% | 再提升 +50% | 更快深入 |
| 引擎 | 移速 +20% | 携矿减速降低 | 更晚回程仍可能赶上 |
| 货仓 | 容量 3→5 | 容量 5→8 | 单次带回更多资源 |
| 火炮 | 伤害 +35% | 射速 +25% | 更快清怪 |
| 炮轨 | 转向速度 +35% | 过热恢复 +40% | 改善操作容错 |
| 核心站 | 最大生命 +25 并修复 | 立即修复 35 | 用资源换生存空间 |

要求：

- 每项升级最多 2 级；
- 价格逐级上涨；
- 升级后效果必须立即可感知；
- 升级面板暂停游戏，避免首次体验时手忙脚乱；
- 不做随机升级、装备稀有度、前置科技树和永久解锁。

## 10. UI 与反馈

常驻 UI 仅包含：

- 基地生命；
- 下一波倒计时 / 当前波次；
- 当前携带量与基地库存；
- 当前目标提示。

首次游玩使用短句式引导：

1. “向下挖掘，寻找晶矿”；
2. 拾到矿后：“把晶矿带回核心站”；
3. 回到基地：“购买一项升级”；
4. 警报出现：“敌袭将至，返回炮台”；
5. 第一波后不再弹出强制教学。

必要反馈：

- 挖掘：方块裂纹分级、碎屑、轻微停顿、材质差异音效；
- 获矿：高亮、清脆声音、拖挂动画；
- 警报：倒计时、环境变色、声音逐渐紧张；
- 命中：敌人闪白、击退、炮击震动；
- 升级：数值变化和角色 / 武器表现同步增强；
- 失败和胜利：3 秒内给出“重新开始”按钮。

## 11. 美术与音频范围

### 11.1 美术

- 2D 侧视像素风或低分辨率手绘风；
- 强调地表冷色、地下暖色矿光的对比；
- 第一版只需：玩家 1 套、基地 1 套、方块 5 类、敌人 3 类、炮击与破碎特效；
- 可以程序生成或使用临时图形，但轮廓和颜色必须保证信息可读；
- 不照搬《Dome Keeper》的角色、穹顶造型、怪物轮廓、UI 与素材。

### 11.2 音频

- 地下使用低密度环境音；
- 挖掘不同材质有区别；
- 波次临近时音乐逐层增加节奏；
- 防守结束后迅速回落到安静状态；
- 第一版不需要语音。

## 12. 暂不实现

以下全部不进入第一版：

- 多角色、多基地、多武器；
- 永久成长、局外货币、每日任务；
- 道具、遗物、随机事件和复杂科技树；
- 地下敌人、Boss、地下战斗；
- 基地自由建造、生产链与自动化；
- 多人联机、排行榜、云存档；
- 手柄和移动端触控适配；
- 大量随机地图、生物群系与剧情。

## 13. 最小可玩验收标准

第一版完成必须同时满足：

1. 玩家能从基地进入地下，挖通至少两种耐久不同的方块；
2. 晶矿能被发现、拾取、负重运输并存入基地；
3. 波次倒计时能迫使玩家判断回程时机；
4. 玩家能操作炮台消灭 3 种敌人，基地能受伤和失败；
5. 至少 6 条升级能正常购买并产生可感知效果；
6. 存在完整胜利路径：取得地核晶体并守住最终波；
7. 新玩家无需说明书，1 分钟内能走完一次“挖—运—升—守”；
8. 一局能在 8～12 分钟内结束；
9. Chrome 桌面端稳定运行，无阻断流程的错误；
10. 可一键重新开始。

## 14. 建议开发顺序

### Milestone A：30 秒玩具

- 单屏地下；
- 移动、挖掘、掉矿、搬运；
- 目标是先确认“挖开方块和拖矿”手感是否舒服。

### Milestone B：核心循环

- 加入基地、倒计时、单一敌人与炮台；
- 完成一次“挖—运—升—守”；
- 这是最重要的内部试玩节点。

### Milestone C：完整单局

- 3 种敌人、6 个波次、升级树、地核晶体、胜败；
- 调整至 8～12 分钟。

### Milestone D：展示质量

- 新手引导、音效、粒子、屏幕震动、升级表现；
- 部署为可直接分享的网页 Demo。

## 15. 第一版最关键的测试问题

试玩后不要先问“内容够不够多”，只记录以下问题：

1. 玩家是否会主动产生“再挖一块再回去”的贪心？
2. 玩家是否至少有一次因为回程太晚而紧张？
3. 采掘升级和防御升级之间是否真的难以取舍？
4. 第一次升级后，玩家是否明显感觉效率提升？
5. 失败后，玩家是否知道下一局应该改变什么？
6. 玩家是否愿意立刻再开一局？

如果前 3 个问题不成立，继续增加怪物、装备或地图都没有意义，应先调整回程距离、波次时间、矿物分布和升级价格。

## 16. 设计依据与差异化边界

《Dome Keeper》的官方介绍将体验概括为防守、发展与探索：操作武器抵御来自空中和地面的敌人，并在钻头、移动和穹顶防御之间分配升级资源。相关资料也明确指出，采矿阶段与战斗阶段构成核心循环，资源包含铁、水和钴；默认模式通过深入地下寻找遗物完成目标。

本需求只吸收其“时间压力下的采掘 / 回防 / 升级取舍”结构。第一版改用单一资源、短局、固定小型地图和自己的基地 / 地核设定，主动排除其具体角色、美术、穹顶、装备、数值和内容组合。
