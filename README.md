# Coreward / 地核守望

一款面向浏览器的 2D 单人采掘 + 波次防守游戏原型。

核心问题只有一个：**再挖一点，还是现在回去？**

## 当前版本

首个可玩原型（Milestone B）包含：

- 四方向移动、松土与硬岩挖掘；
- 晶矿发现、可视化携带、返回基地存入；
- 6 条两级升级路线；
- 采掘倒计时、炮台操作、敌人、基地生命与胜败；
- 一键重开和基础新手引导；
- GitHub Pages 自动部署。
- B+C 高清像素风视觉资源：赤锈荒星、青绿工业机械、古代遗迹与紫色晶体；
- 独立采掘车、核心站以及爬行兽、飞行虫、重甲兽三类敌人素材。

下一阶段将完成 V0.1 的 3 种敌人、6 个波次、地核晶体与 8～12 分钟完整单局。

## 操作

| 按键 | 行为 |
| --- | --- |
| `WASD` / 方向键 | 移动、朝方块持续挖掘；炮台中旋转炮口 |
| `E` | 在基地打开或关闭升级面板 |
| `Space` | 炮台射击 |
| `Esc` | 关闭升级面板 |

## 本地运行

这是一个无依赖的静态网页。在仓库目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

完整策划与验收范围见 [`docs/V0.1-requirements.md`](docs/V0.1-requirements.md)。
